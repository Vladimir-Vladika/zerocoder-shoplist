# ShopList

Учебная витрина товаров на Django: каталог с поиском, страницы товаров с изображением, ценой и адресами, регистрация и панель управления для менеджеров.

## Возможности

- Поиск по названию, в том числе без учёта регистра русских букв, и разбиение каталога на страницы.
- Регистрация и вход; зарегистрированные пользователи могут просматривать товары.
- Менеджеры создают, редактируют и удаляют товары через панель `/manage/`.
- Суперпользователь управляет товарами и пользователями также через `/admin/`.
- При обычной регистрации роль менеджера получить нельзя. Группу «Менеджеры» назначает администратор.

## Запуск в Windows и PyCharm

Нужен Python 3.10 или новее. Откройте папку проекта в PyCharm, затем откройте вкладку **Terminal** и выполните команды по очереди:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Если PowerShell запрещает активацию, выберите терминал Command Prompt и выполните `.venv\Scripts\activate.bat`, либо используйте `.venv\Scripts\python.exe` вместо `python` в командах. Пароль при вводе в терминале не отображается — это нормально.

Откройте http://127.0.0.1:8000/ — на первом запуске каталог пуст. Войдите под суперпользователем и добавьте товар через «Управление» или админку http://127.0.0.1:8000/admin/. Для остановки сервера нажмите Ctrl+C.

## Назначение менеджера

1. Зарегистрируйте обычного пользователя на сайте.
2. Войдите в `/admin/` под суперпользователем, откройте **Пользователи**, выберите нужного пользователя.
3. В разделе групп добавьте группу **Менеджеры**, созданную миграцией, и сохраните изменения. Флаг «Статус персонала» для панели `/manage/` не нужен.
4. Войдите под этим пользователем и откройте «Управление». Чтобы убрать права, удалите пользователя из группы.

В поле адресов указывайте каждый адрес с новой строки. Изображения сохраняются в `media/products/` и не включаются в Git. Вручную удалённые товары и заменённые картинки автоматически не очищают файлы с диска.

## Проверка

```powershell
python manage.py check

```

## Устройство

`catalog/models.py` описывает товар и хранение адресов; `forms.py` проверяет ввод; `views.py` обрабатывает запросы и проверяет доступ; `urls.py` связывает адреса сайта с обработчиками. `templates/` содержит HTML, `static/css/` — оформление, `config/` — настройки Django. База SQLite создаётся локально после миграций.

## Примечания

Проект настроен для локального учебного запуска. Для публикации нужны отдельный секретный ключ, отключённый DEBUG, настроенные ALLOWED_HOSTS, HTTPS и корректная раздача static/media. Не публикуйте базу с пользовательскими данными и загруженные файлы. Bootstrap загружается с CDN и для полного оформления требует интернет. Поиск на SQLite выполняется в Python для поддержки русских букв и рассчитан на небольшой учебный каталог. Django 4.2 выбран по требованию задания; для реального развёртывания следует перейти на поддерживаемую версию Django и проверить совместимость.
